## Как опубликовать

1. Юлия читает черновик и присылает правки.
2. Текст переносится в `src/pages/blog/<адрес>.astro` по образцу существующих статей.
3. Статья добавляется в `src/data/posts.ts` — оттуда её возьмут блог, главная, блок «Читайте также», разметка и лента RSS.
4. Для обложки нужна настоящая фотография (не сток с чужими людьми) и подпись к ней в `posts.ts`.
