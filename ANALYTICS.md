# Счётчики и кабинеты поисковиков: что сделать руками

На сайте всё готово. Осталось завести четыре кабинета и прислать четыре кода —
они вписываются в один файл `src/data/analytics.json`, и после выкладки всё
заработает. Пароли и ключи никому присылать не нужно, только коды ниже.

Заводите всё на аккаунты Юлии (или на свои, но с доступом для неё): кабинеты
привязаны к владельцу сайта.

Что прислать в итоге:

| Что | Как выглядит | Откуда |
|---|---|---|
| Номер счётчика Метрики | 8 цифр, например `12345678` | шаг 1 |
| Код Вебмастера | длинная строка из букв и цифр | шаг 2 |
| Идентификатор GA4 | `G-XXXXXXXXXX` | шаг 3 |
| Код Search Console | длинная строка из букв и цифр | шаг 4 |

---

## 1. Яндекс Метрика (5 минут)

1. Откройте <https://metrika.yandex.ru> и войдите под аккаунтом Яндекса.
2. «Добавить счётчик». Имя — `julialyapina.ru`, адрес сайта — `julialyapina.ru`.
3. **Вебвизор не включать.** Он записывает, что человек печатает в полях, а
   на сайте психолога это «что вас беспокоит». В коде он тоже выключен.
4. Примите условия, нажмите «Создать счётчик».
5. Код счётчика на сайт ставить не нужно — он уже есть. Скопируйте только
   **номер счётчика** (цифры рядом с названием) и пришлите мне.

Когда счётчик заработает, заведите цели: «Цели» → «Добавить цель» → тип
«JavaScript-событие». Идентификаторы ровно такие:

| Идентификатор | Что это |
|---|---|
| `booking_submit` | отправлена форма записи |
| `contact_submit` | отправлена форма на странице контактов |
| `test_submit` | пройден тест |
| `phone_click` | нажат телефон |
| `whatsapp_click` | нажат WhatsApp |
| `telegram_click` | нажат Telegram |
| `email_click` | нажата почта |

## 2. Яндекс Вебмастер (5 минут)

1. Откройте <https://webmaster.yandex.ru>, нажмите «Добавить сайт».
2. Адрес: `https://julialyapina.ru`.
3. Способ подтверждения — **«Метатег»**. Яндекс покажет строку вида
   `<meta name="yandex-verification" content="a1b2c3d4e5f6" />`.
4. Пришлите мне то, что в кавычках после `content=`. Кнопку «Проверить» пока
   не нажимайте — нажмёте после того, как я выложу код.

После подтверждения:

- «Индексирование» → «Файлы Sitemap» → добавить `https://julialyapina.ru/sitemap.xml`.
- «Представление в поиске» → «Региональность» → выбрать Лесной Городок (если
  его нет в списке — Одинцово), страница-подтверждение
  `https://julialyapina.ru/contact/`.
- «Индексирование» → «Переобход страниц» → отправить главную, `/contact/`,
  `/services/children/`, `/services/school-prep/`, `/services/adult/`.
- «Настройки» → «Привязка к Метрике» → привязать счётчик из шага 1.

## 3. Google Analytics 4 (5 минут)

Сначала решите, нужен ли он. Данные GA4 уходят на серверы Google за рубежом —
для российского сайта с формами это отдельный юридический риск. Метрика
показывает то же самое. Если не уверены — пропустите этот шаг, сайт работает
и с одним счётчиком.

1. Откройте <https://analytics.google.com>, «Начать измерения».
2. Аккаунт — `Юлия Ляпина`, ресурс — `julialyapina.ru`, часовой пояс Москва,
   валюта рубль.
3. Платформа — «Веб», адрес `https://julialyapina.ru`, название потока — любое.
4. Пришлите мне **идентификатор потока данных** — он начинается с `G-`.

## 4. Google Search Console (5 минут)

1. Откройте <https://search.google.com/search-console>, «Добавить ресурс».
2. Выберите правую колонку — **«Префикс URL»**, впишите `https://julialyapina.ru/`.
3. Способ подтверждения — **«Тег HTML»**. Google покажет строку вида
   `<meta name="google-site-verification" content="AbCdEf123456" />`.
4. Пришлите мне то, что в кавычках после `content=`. «Подтвердить» нажмёте
   после выкладки.

После подтверждения:

- «Файлы Sitemap» → добавить `sitemap.xml`.
- «Проверка URL» → вставить главную → «Запросить индексирование»; то же для
  `/contact/`, `/services/children/`, `/services/school-prep/`.

## Что будет на сайте, когда коды появятся

- Внизу экрана появится небольшая плашка: «Сайт использует файлы cookie…» с
  кнопками «Хорошо» и «Не нужно». Счётчики включаются только после «Хорошо».
  Часть посетителей откажется, и в статистике их не будет — это плата за то,
  что сайт психолога не следит за человеком без спроса.
- Если захотите считать всех, это один переключатель: в
  `src/data/analytics.json` поставить `"requireConsent": false`. Плашка тогда
  только сообщает.
- В политике конфиденциальности сам появится абзац с названиями подключённых
  счётчиков и кнопкой «изменить выбор».

Через две-три недели в Вебмастере («Мониторинг запросов») и в Search Console
(«Эффективность») станет видно, по каким словам сайт показывают. Смотрите на
запросы со словами «Лесной городок».
